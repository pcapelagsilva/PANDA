# 🐼 Manipulação de Dados com Pandas

Repositório focado no estudo da biblioteca **Pandas** para análise de dados, com ênfase em limpeza, transformação e análise exploratória (EDA).

### 🛠️ Competências Demonstradas:
* **Data Wrangling**: Tratamento de datasets complexos e limpeza de dados faltantes.
* **Agregação**: Operações de agrupamento e estatística descritiva.
* **Contexto Bio**: Aplicação de DataFrames em matrizes de expressão gênica e dados clínicos.

> **Meta:** Garantir a qualidade dos dados antes de qualquer implementação de Machine Learning.
